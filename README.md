# ISEN 370 Engineering Statistics
## Project 1: Data Visualization

### Project Overview

This project introduces the use of data science tools to analyze and visualize
engineering data. You will use Python in Google Colab to perform descriptive
statistical analysis and create appropriate data visualizations.

This is a team project. Teams will consist of 4–5 students. Each team will
work collaboratively using a GitHub repository provided through the ISEN 370
GitHub organization.

Detailed project requirements, due dates, grading criteria, team assignments,
and submission instructions are provided in Canvas.

---

## Repository Contents

Your team's Project 1 repository contains the files needed to complete the
project:

- `ISEN_370_Project_1_Assignment.ipynb` – Project notebook that your team
  will complete.
- `ISEN_370_Project_1_Demo.ipynb` – Demonstration notebook containing
  examples that may be helpful as you complete the project.
- Project dataset – Data file used for the analysis.
- `README.md` – Instructions for working with the project repository.

---

## Accessing Your Team Repository

Each team will be assigned a Project 1 repository within the ISEN 370 GitHub
organization.

You do **not** need to create your own copy of this repository.

1. Make sure you have a GitHub account.
2. Use the GitHub username associated with the account you intend to use
   for this course.
3. Follow the instructions in Canvas for joining the ISEN 370 GitHub
   organization and accessing your team's repository.
4. Accept any GitHub invitations associated with the organization or your
   project team.
5. Open the Project 1 repository assigned to your team.
6. Verify that you can access the project files before beginning your work.

**Important:** Do not create a separate copy of the Project 1 repository.
All members of your team should collaborate using the repository assigned
to your team.

---

## Working with Google Colab

The project notebook can be opened and edited using Google Colab.

1. Open your team's Project 1 repository in GitHub.
2. Select `ISEN_370_Project_1_Assignment.ipynb`.
3. Select **Open in Colab**.
4. Sign in to your Google account if prompted.
5. Run notebook cells using the **Run** button beside each code cell.
6. Add or modify Python code as required by the project instructions.
7. Use the demonstration notebook as a reference when needed.

Follow the detailed Project 1 instructions in Canvas when completing the
analysis and visualizations.

---

## Saving Your Work to GitHub

Your completed work should be saved in your team's GitHub repository.

When working in Google Colab:

1. Save your work regularly.
2. From the Colab menu, select **File → Save a copy in GitHub**.
3. Select your team's Project 1 repository in the ISEN 370 GitHub
   organization.
4. Save the updated notebook using the appropriate filename.
5. Enter a brief commit message describing the work completed.
6. Confirm that the updated notebook appears in the team repository.

Do not rely only on an open Colab session to store your work. Verify that
your team's most recent work has been saved to GitHub.
